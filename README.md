# pitwall-lima# 🏎️ PITWALL — GP de São Paulo

## 📌 Sobre o projeto

O **PITWALL** é um projeto de desenvolvimento web criado durante as aulas do curso Técnico em Desenvolvimento de Sistemas do SENAI.

O objetivo da atividade é reproduzir uma página inspirada no universo da Fórmula 1, utilizando **HTML5 e CSS3**, com um layout moderno, organizado e responsivo para computadores e celulares.

O site apresenta informações sobre o Grande Prêmio de São Paulo, realizado no Autódromo de Interlagos.

## 🚀 Funcionalidades

O projeto possui as seguintes seções:

- 🏁 **Página inicial:** banner do GP de São Paulo com imagem de um carro de Fórmula 1.
- 🏎️ **Grid de pilotos:** cards com pilotos, números e equipes.
- 🏆 **Classificação:** tabela demonstrativa com posições, equipes, vitórias e pontos.
- 🎟️ **Ingressos:** setores, preços ilustrativos e formulário de reserva demonstrativo.
- 📱 **Design responsivo:** adaptação da página para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** estilização, cores, posicionamento e responsividade.
- **Visual Studio Code:** editor utilizado no desenvolvimento.
- **Live Server:** extensão para visualizar o projeto no navegador.

## 💻 Como executar o projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Verifique se os arquivos `index.html` e `styles.css` estão na mesma pasta.
4. Abra o arquivo `index.html`.
5. Utilize a extensão **Live Server** para visualizar o site no navegador.

## 🎨 Design e responsividade

O PITWALL utiliza uma identidade visual inspirada no automobilismo, com predominância das cores **preto, vermelho e branco**.

O layout foi desenvolvido com CSS Grid, Flexbox e Media Queries, permitindo a adaptação dos elementos para diferentes dispositivos.

## 🎯 Objetivo da atividade

Aplicar os conhecimentos adquiridos durante as aulas de Linguagem de Marcação, desenvolvendo uma página web a partir de uma referência visual.

Os principais conceitos utilizados foram:

- Estruturação de páginas com HTML.
- Estilização com CSS.
- Organização de elementos.
- Utilização de imagens.
- Criação de tabelas e formulários.
- Desenvolvimento de layouts responsivos.

## ⚠️ Observação

Este projeto foi desenvolvido exclusivamente para fins educacionais.

As informações de classificação e os preços dos ingressos são ilustrativos. O formulário não realiza reservas ou compras reais.
